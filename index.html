About

I'm an SDET with 10+ years building test automation frameworks from scratch in Java, TypeScript and C#. I shipped a BDD framework for a platform managing 1.4M+ vehicles, automated a canvas-rendered trading UI with no addressable DOM, and built CI/CD test pipelines in Jenkins and Azure DevOps.

Today I'm hands-on in Playwright with TypeScript across five applications, while setting automation standards for a 20-engineer QA function. I'm deliberately choosing a hands-on engineering track over a management one.

I'm completing an M.Tech in AI & Machine Learning (2026), focused on LLM evaluation and testing. Outside work, I build web and mobile apps end to end. Building software shows me where it breaks; automation is how I make sure it doesn't.

Selenium UI Framework

6 tests passing

End-to-end UI automation for an e-commerce demo site: login, cart and checkout.

  • Page Object Model with fluent chaining between pages
  • Factory + ThreadLocal driver management for safe parallel runs
  • Explicit waits only, with no Thread.sleep
  • Data-driven login tests with TestNG @DataProvider
  • Listeners: a screenshot on failure, and a retry for flaky failures

REST Assured API Framework

16 tests passing

API automation against two public APIs: booking CRUD with token auth, and real JWT authentication.
